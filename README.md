# 📊 COVID-19 Data Analysis using Python

A short and efficient Exploratory Data Analysis (EDA) project that analyzes the global impact of COVID-19 using early-stage pandemic data.

## 📌 Project Overview
This project processes global COVID-19 datasets to identify infection trends, mortality numbers, and recovery patterns across different countries and regions.

## 🛠️ Key Features
* **Data Cleaning:** Handled missing and incomplete entries using Pandas.
* **Statistical Analysis:** Grouped and aggregated case reports by geographical regions.
* **Data Visualization:** Created impactful charts using Matplotlib and Seaborn to pinpoint high-risk zones.

## 🚀 Tech Stack
* **Language:** Python
* **Libraries:** Pandas, Matplotlib, Seaborn
* **Tool:** VS Code / Jupyter Notebook

## 📈 Key Visualizations Included
* Top 10 worst-affected regions globally.
* Regional comparison of Confirmed vs. Recovered cases.
* Specific case breakdown for regions like India and the US.

## 💻 How to Run
1. Clone this repository.
2. Install dependencies: `pip install pandas matplotlib seaborn`
3. Open the `.ipynb` file in VS Code or Jupyter Notebook and run the cells.
